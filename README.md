# 🍳 Recipe Page

A simple and responsive **Recipe Page** built using **HTML**.
This project was created to practice HTML structure, content organization, images, lists, and links while building a real-world webpage.

## 🌐 Project Overview

The Recipe Page displays a recipe in a clean and easy-to-read format. It includes the recipe title, ingredients, instructions, and other relevant information.

## ✨ Features

* 🍽️ Recipe title and description
* 🥕 Ingredients list
* 👩‍🍳 Step-by-step cooking instructions
* 🖼️ Recipe image
* 📱 Simple and clean webpage layout
* 🔗 Structured HTML elements
* 💻 Beginner-friendly project

## 🛠️ Technologies Used

* **HTML5**
